Rooms Generation Tool

A Unity package that cuts a space into connected rooms with Binary Space Partitioning, then furnishes them with your own prefabs. Same seed, same map. The background of this page runs the same idea.

  • Installs in one step with the Package Manager
  • Furniture on a grid, no overlaps, every room reachable
  • Room data API to place a player, enemies or an exit
